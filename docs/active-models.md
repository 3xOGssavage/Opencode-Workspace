## How to Run

```powershell
pwsh -File scripts/check-model-health.ps1
```

This:

1. Probes all 5 providers in parallel via `Start-Job` (5-second timeout each)
2. Checks each model the provider exposes
3. Writes results back to this file (preserving secrets from `auth.json` â€” never writing tokens here)
4. Prints a one-line summary to stdout (suitable for Task Scheduler logging)

## Refresh Frequency

- **Recommended**: weekly via Task Scheduler (Sunday 09:00 local)
- **Manual**: any time provider changes are made
- **After provider outage**: re-run to verify recovery
